## STRICT UI MODAL POLICY (ATURAN MUTLAK TANPA MODAL UNTUK CREATE & UPDATE):
> [!CAUTION]
> DILARANG KERAS MENGGUNAKAN MODAL, POPUP, DIALOG, ATAU MODAL OVERLAY UNTUK OPERASI CREATE DAN UPDATE (TAMBAH DATA & EDIT DATA).
> Seluruh formulir penambahan data baru (Create) dan pengeditan data (Update) HARUS disajikan secara langsung penuh di dalam halaman (IN-PAGE FULL SECTION / FULL VIEW).
> Satu-satunya pengecualian yang diperbolehkan menggunakan Modal Dialog adalah konfirmasi HAPUS DATA (Delete).
